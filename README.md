Proyecto trabajadores y sueldo
Este sistema dispone de los datos de distintos tipos de trabajadores en una empresa y calcula su sueldo mediante los metodos nesesarios segun su puesto

No entendi bien que eran las pruebas de usuario y lo busque en internet, aun asi, estan en el documento escritas porque no encontre ninguna plantilla favorable

Criterios de aceptación
Crear trabajadores con datos correspondientes
Que el sueldo sea privado
Que cada trabajador tenga un sueldo fijo (aunque sea de 0 en el caso de los pasantes)
 Si quiere cambiar el sueldo, no puede ser negativo
 Cada sueldo que aparezca en la consola debe aparecer con el tipo de cargo del trabajador
